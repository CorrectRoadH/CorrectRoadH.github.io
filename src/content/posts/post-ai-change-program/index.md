23年发了一篇: AI是否会带来编程范式上的改变。简单预测了一些方向。现在回头再看，虽然还没有做到，但是感觉依然没有太多区别。

思考最近在不断学习的AI Coding，最近编程范式变化非常快速，从Prompt Engineering到context，再到Spec。通过实践起来确实不好说哪个才是真的未来。

但是最佳实践在反复变化是很奇怪的。比如Cursor用Code Index看起来就是走错了路，像各种Code Cli都是在用Grep。
[揭开 Claude Code 的面纱](https://mp.weixin.qq.com/s/XpSh1xYo_uc8dVDOaHXacA)


再总结一下最近的思考，最近跑步的时候一直在听播客，确实听到挺多有意思的播客。
比如这个[E084 错误：如何认识失败以及如何塑造自我](https://www.xiaoyuzhoufm.com/episode/68db405cb4befcf7309249c4) 。感觉挺有意思的，再联想到马督工谈自己的错误。
